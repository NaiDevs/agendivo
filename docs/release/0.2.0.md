# Release candidate 0.2.0 — Windows

Fecha: 2026-08-22

## Alcance

- Autenticación e invitaciones mediante Supabase Auth.
- Sincronización bidireccional y aislamiento por negocio.
- Suscripciones mediante Stripe Checkout.
- Configuración y emisión de documentos fiscales.
- Campos personalizados para clientes.
- Múltiples servicios por cita y pago.

## Preflight

- TypeScript: aprobado.
- ESLint: aprobado sin warnings.
- Prettier: aprobado.
- Vitest: 124 pruebas aprobadas en 30 archivos.
- Auditoría de dependencias de producción: cero vulnerabilidades conocidas.
- Build web de producción: aprobado.
- `cargo check`: aprobado.
- Build Tauri NSIS y MSI: aprobado.

El build web conserva una advertencia no bloqueante por chunks mayores de 500 kB.

## Infraestructura validada

- Supabase Auth responde correctamente.
- Las tablas y columnas requeridas por la versión 0.2.0 están disponibles.
- Las funciones RPC de sincronización están registradas y rechazan acceso anónimo.
- Las diez migraciones Supabase coinciden con las aplicadas en remoto.
- Las cuatro Edge Functions están activas y su configuración JWT coincide con
  `supabase/config.toml`.
- Todos los secretos requeridos de Supabase y Stripe están configurados.
- El webhook de Stripe tiene secreto configurado y rechaza firmas inválidas.
- La política CSP limita las conexiones remotas al proyecto Supabase de Agendivo.
- La aplicación valida que Stripe Checkout abra únicamente URLs HTTPS oficiales.

## Rollback

1. Crear un respaldo local antes de actualizar.
2. Desinstalar 0.2.0 si presenta problemas.
3. Reinstalar 0.1.0.
4. Restaurar el respaldo desde Agendivo.

Las migraciones Supabase cuentan con scripts inversos en `supabase/rollback` y
deben ejecutarse en orden descendente únicamente después de respaldar la base.
