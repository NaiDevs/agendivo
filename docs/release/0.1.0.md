# Release 0.1.0 — Windows

Fecha: 2026-08-03

## Alcance

Primera distribución instalable de Agendivo. Incluye las Fases 1 a 4:
configuración, catálogos, citas, finanzas, reportes, comprobantes y respaldos.

## Preflight

- TypeScript, ESLint y Prettier sin errores.
- 68 pruebas Vitest aprobadas.
- Build web de producción aprobado.
- `cargo check` aprobado.
- Prueba real de respaldo/restauración aprobada con integridad SQLite y hash
  idéntico al respaldo.

## Artefactos

- `Agendivo_0.1.0_x64-setup.exe` para instalación sencilla por usuario.
  - SHA-256: `1355CFD832855CFB2BB4D226B87FEC14DB0B3AB9E1E44611052DAC004A6A0FA7`
- `Agendivo_0.1.0_x64_es-ES.msi` para despliegues administrados en Windows.
  - SHA-256: `AB281D37F0838ED4B64DE97B032108819E3E3659251ED761268C4E04C60528F7`

Los artefactos se generan en `src-tauri/target/release/bundle`.

## Validación de instalación

- NSIS: instalación silenciosa, arranque de la aplicación y desinstalación
  aprobados.
- Persistencia: la base local conservó el mismo SHA-256 antes y después de
  desinstalar.
- MSI: extracción administrativa y contenido aprobados. La instalación MSI
  requiere una sesión con privilegios de administrador, como corresponde a su
  alcance para todos los usuarios.
- Upgrade: se validará al generar `0.1.1`, ya que `0.1.0` no tiene una versión
  distribuida anterior.

## Firma

Esta versión se genera sin firma digital. Antes de distribución pública debe
configurarse un certificado de firma de código y timestamp.

## Rollback

1. Crear un respaldo desde Configuración antes de actualizar.
2. Desinstalar la versión que presenta problemas.
3. Instalar nuevamente la versión estable anterior.
4. Restaurar el respaldo desde la pantalla de bienvenida.

La base local no debe eliminarse durante una desinstalación o rollback.
