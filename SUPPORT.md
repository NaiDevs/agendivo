# Soporte de Agendivo

Para solicitar ayuda o reportar un problema, escribe a
[naidelynmaldonado54@gmail.com](mailto:naidelynmaldonado54@gmail.com).

Incluye, cuando corresponda:

- Versión de Agendivo.
- Versión de Windows.
- Descripción del problema y pasos para reproducirlo.
- Captura del mensaje de error, sin contraseñas, datos bancarios ni información
  personal de clientes.

No adjuntes respaldos de Agendivo por correo. Estos archivos pueden contener datos
personales y financieros del negocio.
